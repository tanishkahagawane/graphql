# GraphQL - NodeJS & React

This repository contains the source code for a beginner-friendly course on **GraphQL**. This project demonstrates how to set up a GraphQL server using _Node.js_ and _Apollo Server_ and how to integrate it with a _React_ frontend.

## Project Overview

This tutorial covers:

- **Introduction to GraphQL:** Understanding how it solves common _REST API_ issues like over-fetching and under-fetching .
- **Server Setup:** Creating a GraphQL server with _Node.js_ using _Apollo Server_ .
- **Schemas and Resolvers:** Defining data types and the logic for fetching data .
- **Frontend Integration:** Connecting a _React_ application using _Apollo Client_ to fetch data efficiently .

## Getting Started

1.  Clone this repository to your local machine.
2.  Navigate to the `server` folder and run `npm install` and `npm start`.
3.  Navigate to the `client` folder and run `npm install` and `npm start`.
